# Hisob — do'kon POS

Zifra kabi kassa — oziq-ovqat va ichimliklar do'koni uchun: savdo, ombor, qarz, foyda va ABC tahlil.

## Ishga tushirish

```bash
npm install
npm run dev
```

Brauzerda: http://localhost:3000

Telefon va planshet (shu Wi-Fi): http://192.168.100.17:3000

Chrome/Safari da oching. iPhone: Share → Add to Home Screen. Android: Menyudan "Bosh ekranga qo'shish".

### Demo kirish

- Egasi: `admin` / `admin123`
- Kassir: `kassir` / `kassir123`

Ma'lumotlar `data/hisob.db` faylida saqlanadi (do'kon kompyuterida, internet shart emas).

Telefondan kuzatish uchun shu kompyuterning mahalliy IP manzilini oching, masalan `http://192.168.1.10:3000`.
